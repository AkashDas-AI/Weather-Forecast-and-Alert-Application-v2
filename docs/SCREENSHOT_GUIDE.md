# Screenshot Guide

**Author:** Akash Das  
**Status:** Phase 2 (Screenshots will be captured once the Streamlit UI is built in Phase 9)  
**Last Updated:** 2026-11-27

## 1. Storage Location
Store all captured application screenshots in:
`images/screenshots/`

## 2. Screens to Capture (Planned Phase 9+)
1. **Dashboard Overview:** Full Streamlit layout with location selector and summary metrics.
2. **Current Weather View:** Current temperature, humidity, wind speed, and observation time.
3. **Forecast Charts:** Temperature trend, rainfall probability, and wind/humidity visualizations.
4. **Alert Examples:** Active advisory banners showing triggered threshold rules.
5. **Insights & Reports:** Plain-language forecast summary and CSV/JSON export controls.

## 3. Naming Conventions
Use lowercase snake_case with a numbered prefix or descriptive screen name, for example:
- `01_dashboard_overview.png`
- `02_current_weather_view.png`
- `03_forecast_charts.png`
- `04_alert_advisories.png`
- `05_insights_and_export.png`
